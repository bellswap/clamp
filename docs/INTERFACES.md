# Interfaces

The interfaces the contracts, the bell service, the site and the infrastructure were built against (written 2026-10-18; the code in contracts/src is the source of truth where they differ):

Contracts (Solidity 0.8.26, Foundry, OpenZeppelin for ERC-20 and ERC-4626 and ECDSA):

- IReference: function latest(bytes32 symbol) external view returns (uint256 price8, uint64 timestamp, uint8 tier); function priceAtOrAfter(bytes32 symbol, uint64 t, bytes calldata proof) external returns (uint256 price8, uint64 timestamp). Symbols are bytes32 of the catalog ticker (ASCII, right padded). Tier: 1 session-fast (Chainlink, Pyth), 2 daily (Ondo), 0 demo signer.
- DemoSignerReference (used on the playground): post(bytes32 symbol, uint256 price8, uint64 timestamp, bytes signature) stores rounds per symbol in order; latest and priceAtOrAfter read the stored rounds (proof ignored); the signer address is set at deployment. PythReference(owner, pyth, settleWindow, book): priceAtOrAfter is callable only by the book, parses a Pyth update from proof with parsePriceFeedUpdatesUnique(updateData, [id], t, t + settleWindow) (the first observation at or after t, independent of the stored latest price), pays the fee from its own ETH balance, built and unit tested with a mock Pyth, never deployed on the playground. ChainlinkReference: wraps an AggregatorV3 per symbol and walks rounds for priceAtOrAfter. OndoReference: wraps the existing ReferenceFeed AggregatorV3 face (interface only, tested with a mock). The round walk reverts UnknownHistory when a predecessor round cannot be read and PhaseBoundary on the first round of a later phase; GuardedFeedView serves only the current confirmed round, so OndoReference needs a history-keeping face (confirmed rounds by id) before it can settle.
- HouseVault (ERC-4626 on the playground USDG, 6 decimals; shares 12 decimals through a decimals offset of 6; a deposit or mint of zero shares reverts ZeroShares): deposit and withdraw for LPs limited to free liquidity (USDG balance minus reserved); totalAssets() = USDG balance minus openNet (net stakes of open tickets); reserve(uint256), release(uint256), pay(address to, uint256), collect(address from, uint256), addOpenNet(uint256), subOpenNet(uint256) only by the TicketBook; view reserved(), free(), openNet().
- TicketBook: struct Ticket { address owner; bytes32 symbol; bool long; uint8 leverage; uint8 horizon; uint256 stake; uint256 entryPrice8; uint64 openedAt; uint64 expiry; uint256 reserved; uint8 status; uint256 payout; uint256 settlePrice8 }. open(bytes32 symbol, bool long, uint8 leverage, uint256 stake, uint8 horizon) returns (uint256 id): pulls stake in USDG (approve first), fee = stake * feeBps / 10000 to the vault, reserved = (stake minus fee) * leverage booked in the vault (the book reserves every ticket's full cap per bucket, M_l + M_s; opposite-side netting under-reserved tickets with different entry prices and is future work). settle(uint256 id, bytes calldata proof) permissionless after expiry: move r = (settle minus entry) / entry signed by side, payout = net stake times clamp(1 + leverage * r, 0, leverage) in 1e18 fixed point, pays the owner from the vault, releases the reservation, emits TicketSettled. Markets: listMarket(bytes32 symbol, address reference, uint8 maxLeverage, uint256 maxStake, uint256 oiCap, uint64 maxStaleness) by the owner (house) in this version; open reverts on an unlisted symbol, stale reference, leverage above max, stake above max or oi above cap. Horizons: 0 session (next 21:00 UTC as the daily close on the playground clock), 1 day (24 h, rounded up to the next full hour), 2 week (7 d, rounded up to the next full hour). Events: MarketListed, TicketOpened(id, owner, symbol, long, leverage, stake, entryPrice8, expiry), TicketSettled(id, settlePrice8, payout), Reserved, Released.

Service (bell v2, Bun and TypeScript, at services/bell): GET /state {chainId, block, clockUnix, speed, counts}, GET /catalog (513 entries with listedByRobinhood, sector, marketCap, listed flag "onChain" when the symbol has a market), GET /charts/:range (the first demo's charts layer, Yahoo delayed on the server), GET /prices/:symbol (last 300 demo signer rounds), POST /faucet {address} (fork ETH and USDG from anvil dev account 0; rate limited per address), GET /tickets?owner=, GET /tickets/:id, GET /activity (last 200 events), GET /leaderboard (points per address: settled tickets, wins, net pnl), GET /vault (assets, reserved, free, lp count), admin POST /replay {speed, range} with Authorization Bearer. Loops: replay (posts DemoSigner rounds from recorded series every tick and advances the anvil clock with evm_increaseTime and evm_mine so one playground day passes in about one wall minute), settler (calls settle for every expired ticket), indexer (event log to a JSON state file on a volume).

Site (Vite 7, React 19, viem, Bun, at site/): routes / (the board: tickers with sparklines, movers since the open, the toggle "Show tickers Robinhood Chain lists" off by default, search, sort), /t/:symbol (the ticket flow: side, multiple, stake, horizon, one confirm; shows the reference, the max payout and the max loss), /ticket/:id (watch: live reference, current payout, countdown on the playground clock; after settlement the verdict and a share card), /me (my tickets), /leaders (leaderboard), /vault (house vault: assets, reserved, free, deposit and withdraw for the playground), /activity (every ticket and settlement, per address filter). Chain config: chain id 46633, RPC VITE_RPC_URL, bell VITE_BELL_URL, contract addresses from VITE_BOOK_JSON (deployments/book.json written by the deploy script). Burner wallet in localStorage with a faucet call on first visit and a connect button for external wallets. One disclaimer line in the footer and one in the ticket confirm.

Infrastructure (at infra/): docker-compose with anvil (foundry image, fork of Robinhood Chain through the retry proxy infra/fork/upstream-proxy.py, chain id 46633, state on a volume), erpc (public method allowlist, infra/erpc/erpc.yaml, with CORS for play.bellswap.fun, localhost and the Pages previews), bell (built from the repo), caddy (TLS for rpc-play.bellswap.fun and api-play.bellswap.fun). Deploy script: rsync the repo to the VM over SSH, docker compose up, deploy contracts with forge script against the fork (dev account 0), write deployments/book.json, seed the house vault and list the markets, start the replay.
